      How it works
      1 · Hardware

      OCR reads the number, weighbridges and crane load cells weigh the box, IoT probes read reefer temperature, UWB/BLE tracks location.

      2 · Software

      The gateway network carries the signals to the IoT platform, which joins them to the booking and checks each scale against the others.

      3 · ProTrack

      Decides which source to trust, scores every box, and sorts it into Release, Slow, Reroute or Inspect.

      Simulated shift, 101 example boxes. Trust order: customs hold > sensors that agree > carrier and shipper declarations.
